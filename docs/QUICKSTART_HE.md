# PTBot 3.6.7 — איסוף מידע על אתר

## מה נוסף

השם בתפריט השתנה ל־**Assessments**. בכל התקשרות אפשר לבחור Website Recon, בדיקת XSS או Workbench. מודול XSS הקיים נגיש כבדיקה בפני עצמה.

ב־Website Recon מזינים כתובת אתר ובוחרים את המידע לאיסוף. הדשבורד מרכז IP ו־DNS, שמות תתי־דומיינים ומקורם, פרטי HTTP ו־TLS, טכנולוגיות, חתימות WAF/CDN ופורטי TCP. בכל מודול מוצג אם הצליח, נחסם לפי ההרשאות, חסר בהתקנה או הסתיים חלקית.

## התקנה והפעלה

חלץ את ZIP לתיקייה חדשה. פתח טרמינל בתיקיית PTBot-3.6.7:

```bash
bash install.sh
bash install-recon.sh --whatwaf
.venv/bin/python manage.py init
.venv/bin/python manage.py user
bash start.sh
```

גש לכתובת `http://127.0.0.1:5000`.

אם יש נתונים מגרסה קודמת, עצור את השרת הקודם והעתק את מסד הנתונים באמצעות `scripts/copy_database.py` לפי README, לפני הרצת `manage.py init` בתיקייה החדשה. השם של מסד הנתונים נשאר ptbot-3.5.4.db לשמירת תאימות; גרסת התוכנה היא 3.6.7. עדכון הסכמה מוסיף טבלה ואינו מוחק מידע.

## הגדרת בדיקה

1. צור Engagement והכנס Domain מדויק לסקופ. אם נדרשת הגבלה לנתיב, הגדר URL והחרגות מתאימות.
2. סמן את ההרשאות המתאימות: `dns_lookup`, `http_request`, `tls_inspect`, `technology_fingerprint`, `port_scan`, `subdomain_discovery`.
3. אשר את ההתקשרות. לא מתווספות הרשאות אוטומטית להתקשרויות ישנות.
4. פתח **Assessments → Website Recon** והזן למשל את הכתובת המאושרת שלך.
5. בחר מודולים ופורטים ולחץ **Start Website Recon**.

במחשב מקומי אפשר לבדוק `http://127.0.0.1:8000/`. כלול בסקופ גם את כתובת ה־URL וגם IP מסוג `127.0.0.1` אם רוצים לבדוק פורטים. עבור כתובת IP, איסוף תתי־דומיינים אינו רלוונטי.

## איך לקרוא את התוצאות

- **IP / DNS**: כתובות ורשומות שנאספו בפועל. כל מודול צורך את התקציב שלו במנגנון ההרשאות.
- **Subdomains**: שמות מתעודות TLS, מקישורי העמוד ומשירות crt.sh. אינם נסרקים אוטומטית ואינם בהכרח פעילים. לחיפוש לצד www, הגדר בשדה Subdomain base את הדומיין הראשי והוסף אותו לסקופ.
- **WhatWeb**: חתימות טכנולוגיות וגרסאות כשהכלי מזהה אותן. נדרש להתקין אותו.
- **WhatWaf**: 89 חתימות בגרסת המקור שנבדקה, המופעלות על תגובת HTTP שנאספה. זהו זיהוי פסיבי; זיהוי ספק CDN אינו מאשר שמדיניות WAF פעילה.
- **Nmap**: עד 16 פורטים לבחירה ב־IP הראשון שנפתר. שם השירות מבוסס על טבלת הפורטים, ללא חקירת גרסאות שירותים.
- **HTTP / TLS**: קוד תשובה, כותרת עמוד, כותרות אבטחה, מאפייני Cookies, תעודה ותוקף. ערכי Cookies לא נשמרים. הפניות מוצגות ללא מעבר ליעד הבא.
- **Coverage**: בדוק את הטבלה גם כשהדוח מכיל מידע. כלי חסר או הרשאה חסרה גורמים לתוצאה חלקית.

כפתורי Export JSON ו־Print / PDF נמצאים בראש התוצאה. ההיסטוריה נשמרת במסד הנתונים ונגישה מ־Assessments.

## מקור הגרסה

העדכון נבנה מקובץ PTBot 3.5.4 שהיה זמין. שינויים בגרסאות ביניים שלא סופקו אינם נכללים בו.
